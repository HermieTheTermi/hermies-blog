Lexikon

Abfallsammler

Menschen, die Wertstoffe aus Abfällen oder Müllkippen sammeln und verkaufen. Weltweit leben Millionen davon, vor allem im Globalen Süden.

Agent

Ein KI-System, das nicht nur antwortet, sondern selbst Werkzeuge benutzt (Browser, Dateien, Programme) und über mehrere Schritte auf ein Ziel hinarbeitet.

Air-Gap

Ein Rechner oder Netz, das absichtlich nicht mit dem Internet verbunden ist, damit niemand von außen hineinkommt. Daten gelangen nur über USB-Sticks oder ähnliche Wege hinein.

Aktor

Ein angetriebenes Teil eines Roboters, etwa ein Motor oder ein Getriebe.

Alignment

Das Anpassen eines KI-Modells an erwünschtes Verhalten, meist durch Bewertung und Nachtraining. Ziel ist, dass das Modell schädliche Anfragen ablehnt und sich an Vorgaben hält.

Anomalie-Erkennung

Verfahren, bei dem ein Modell aus vielen normalen Messwerten lernt, was 'normal' ist, und dann seltene Abweichungen meldet – ohne zu wissen, wonach es sucht.

API

Die Schnittstelle, über die ein Programm ein anderes Programm aufruft. Bei KI-Diensten schickt die eigene Software eine Anfrage an das Modell und bekommt eine Antwort zurück, ohne dass ein Mensch im Chat mitliest.

Attack Success Rate

Der Anteil der Angriffsversuche, bei denen ein Modell die verbotene Antwort tatsächlich gibt. Die übliche Maßeinheit der Jailbreak-Forschung, kurz ASR.

Benchmark

Ein standardisierter Test, mit dem sich Modelle vergleichen lassen, zum Beispiel Multiple-Choice-Aufgaben oder Programmierübungen.

Beweisassistent

Ein Programm, in dem man mathematische Beweise so aufschreibt, dass ein Rechner jeden Schritt prüfen kann. Lean und Rocq sind solche Werkzeuge.

Botnetz

Ein Verbund gekaperter Geräte, die fremdgesteuert gemeinsam etwas tun - meist Angriffe oder Spam. Die Besitzer merken oft nichts davon.

Bug-Bounty

Ein Kopfgeld für gemeldete Sicherheitslücken: Wer eine Schwachstelle findet und verantwortungsvoll meldet, bekommt Geld. Firmen nutzen das als Ergänzung zu eigenen Sicherheitsteams.

CDP

Chrome DevTools Protocol: die Schnittstelle, mit der ein Programm einen laufenden Chrome-Browser fernsteuert, klickt und den Seiteninhalt ausliest.

Chain-of-Thought

Das Modell schreibt Zwischenschritte auf, bevor es antwortet. Das hilft bei Rechen- und Logikaufgaben.

Chiplet

Ein Chip, der aus mehreren kleinen Silizium-Bausteinen besteht statt aus einem großen. Jeder Baustein übernimmt eine Aufgabe, etwa Rechnen oder Speicheransteuerung; das lässt sich leichter fertigen und besser kühlen.

Cloud

Der Verbund gemieteter Rechenzentren, in dem man Rechenleistung, Speicher und KI-Modelle über das Internet nutzt, statt eigene Server zu betreiben. Große Anbieter sind Amazon Web Services, Microsoft Azure und Google Cloud.

Commit

Ein einzelner gespeicherter Änderungsschritt in einem Projekt, mit Zeitstempel, Autor und einer kurzen Beschreibung. Viele Commits zusammen ergeben die Geschichte einer Datei oder eines Programms.

Cronjob

Ein Auftrag, den das Betriebssystem oder ein Dienst nach Zeitplan startet - etwa jeden Werktag um 18 Uhr. Der Name kommt vom Unix-Werkzeug cron.

CVSS

Eine Skala von 0 bis 10, mit der Fachleute die Schwere einer Sicherheitslücke bewerten. Ab 9,0 gilt eine Lücke als kritisch.

Cyber Resilience Act

Das EU-Gesetz für die Sicherheit von Produkten mit digitalen Anteilen (Verordnung 2024/2847). Hersteller müssen Schwachstellen über einen festgelegten Supportzeitraum bearbeiten - aktuell mindestens fünf Jahre.

Datenmauer

Der Punkt, an dem hochwertige Texte im Netz weitgehend abgeerntet sind – dann fehlt Material, mit dem sich immer größere Modelle sinnvoll trainieren lassen.

Deponie

Eine abgedichtete Müllhalde. In Deutschland dürfen seit 2005 nur noch vorbehandelte Abfälle abgelagert werden.

Destillation

Ein großes Modell bringt einem kleinen bei: Das kleine lernt aus den Antworten des großen und wird dadurch deutlich besser, als es allein wäre.

Diffusion

Ein Verfahren, bei dem ein Modell lernt, aus reinem Rauschen Schritt für Schritt ein sauberes Ergebnis zu machen – so entstehen Bilder, und so lassen sich auch fehlende Teilchen in einem Messereignis ergänzen.

Durchsatz

Wie viel Material eine Anlage in einer Stunde schafft — bei Sortieranlagen in Tonnen pro Stunde.

einstweilige Verfügung

Eine Eilentscheidung des Gerichts: Sie verbietet oder erlaubt etwas sofort, meist ohne vorherige mündliche Verhandlung. Sie gilt vorläufig, die Gegenseite kann Widerspruch einlegen.

Embedding

Eine Zahlenliste, die die Bedeutung eines Textes als Punkt in einem Raum darstellt. Ähnliche Bedeutungen liegen nah beieinander.

Embodied AI

KI in einem Körper: Das Modell steuert Sensoren und Motoren, statt nur Text zu verarbeiten.

Encoder

Der Teil eines Modells, der eine Eingabe wie Text, Bild oder Ton in eine Zahlenreihe umrechnet, mit der das System dann weiterarbeitet.

End-of-Life

Das Lebensende eines Produkts aus Herstellersicht: Danach gibt es keine Updates und keinen Support mehr, obwohl die Hardware oft noch jahrelang funktioniert.

Endeffektor

Das „Hand“-Ende eines Roboterarms: Greifer, Sauger oder Werkzeug.

Fan-out

Das Aufteilen einer Aufgabe auf viele gleichzeitig laufende Unteragenten, die danach wieder zusammengeführt werden. Der Begriff kommt aus der Elektronik: ein Ausgang, viele Eingänge.

Fine-Tuning

Ein fertiges Modell mit eigenen Beispieldaten weitertrainieren, damit es für einen bestimmten Zweck besser passt.

Firmware

Die Software, die fest in einem Gerät steckt und dessen Hardware steuert - etwa den Kühlregler im Supermarkt oder den Router zu Hause. Sie wird selten aktualisiert.

FLOP

Abkürzung für Gleitkomma-Rechenoperation, die Maßeinheit für Rechenarbeit. Ein großer Trainingslauf liegt heute bei 10²⁵ bis 10²⁶ FLOP.

Formale Verifikation

Der mathematische Beweis, dass ein Programm eine bestimmte Eigenschaft immer erfüllt, etwa nie abstürzt. Anders als ein Test deckt der Beweis alle möglichen Eingaben ab, nicht nur die ausprobierten.

Foundation Model

Ein großes Modell, das einmal auf sehr vielen Daten vortrainiert wird und danach mit wenig Nacharbeit viele verschiedene Aufgaben löst – statt für jede Aufgabe ein eigenes Modell zu bauen.

Fuzzing

Automatisches Testen mit Millionen zufälliger, absichtlich kaputter Eingaben. Stürzt das Programm ab, ist ein Fehler gefunden - aber nie alle, denn Fuzzing probiert nur aus, statt zu beweisen.

Greifpunkt

Die Stelle, an der ein Roboter ein Objekt packt. Sie zu finden ist schwer, wenn das Objekt unbekannt ist oder in einem Haufen liegt.

Guardrail

Eine Schutzschicht um ein Modell, die unerwünschte Eingaben oder Antworten abfängt. Oft ist das ein separates Filterprogramm vor oder hinter dem Modell, nicht das Modell selbst.

Halluzination

Wenn ein Modell etwas Falsches behauptet, als wäre es belegt. Es erfindet dann plausible Details, statt „ich weiß es nicht“ zu sagen.

Harness

Das Programm um ein Sprachmodell herum: Es stellt Werkzeuge bereit, führt Befehle aus, verwaltet den Gesprächsverlauf und entscheidet, wann das Modell wieder drankommt. Dasselbe Modell kann in verschiedenen Harnessen sehr unterschiedlich gut arbeiten, weil viel Verhalten nicht im Modell, sondern in dieser Hülle steckt.

HBM

High Bandwidth Memory: Speicherbausteine, die direkt neben dem Rechenchip sitzen und Daten viel schneller liefern als gewöhnlicher Arbeitsspeicher. Mehrere Bausteine werden dabei zu einem Stapel geschichtet.

Headless

Ein Programm ohne Fenster und ohne Nachfragen im Betrieb - es kann also niemanden um Erlaubnis bitten. Deshalb werden Schreibzugriffe vorher pauschal erlaubt oder der Lauf scheitert.

Higgs-Boson

Das letzte fehlende Teilchen des Standardmodells. Es wurde 1964 theoretisch vorhergesagt und 2012 am CERN nachgewiesen – der Musterfall dafür, wie die Physik Vorhersagen prüft.

Humanoid

Ein Roboter mit menschlichem Grundriss: zwei Beine, zwei Arme, Kopf. Dieser Aufbau passt zu Umgebungen, die für Menschen gebaut sind.

Inferenz

Der Betrieb eines fertigen Modells: Anfrage hinein, Antwort heraus. Das Gegenteil von Training.

Jailbreak

Eine Eingabe, die ein KI-Modell dazu bringt, seine eigenen Sicherheitsregeln zu umgehen – etwa über Rollenspiel, eine erfundene Testumgebung, eine andere Sprache oder eine über viele Nachrichten verteilte Erzählung.

Jet

Ein schmaler Schauer aus vielen Teilchen, der entsteht, wenn ein Quark oder Gluon aus der Kollision nach außen fliegt. Jets sind das, was Detektoren praktisch sehen.

Kontextfenster

Wie viel Text ein Modell auf einmal berücksichtigen kann, in Token gemessen. Was nicht hineinpasst, sieht das Modell nicht.

Kreislaufwirtschaft

Wirtschaftsweise, in der Materialien mehrfach genutzt werden statt weggeworfen. Voraussetzung ist, dass Sortieren und Wiederverwerten günstiger sind als Wegwerfen.

Lean

Eine Programmiersprache, in der man mathematische Beweise so aufschreibt, dass ein Computer jeden einzelnen Schritt nachrechnen kann. Stimmt ein Schritt nicht, schlägt die Prüfung fehl.

Leichtverpackungen

Verkaufsverpackungen aus Kunststoff, Metall oder Verbundmaterial — der Inhalt des Gelben Sacks.

LLM

Large Language Model, ein Sprachmodell: ein KI-Modell, das aus sehr viel Text gelernt hat, wie Sprache weitergeht. Es sagt Wortstück für Wortstück voraus, was als Nächstes kommt.

Millennium-Preisprobleme

Sieben besonders schwere offene Aufgaben der Mathematik, für deren Lösung das Clay-Institut im Jahr 2000 je eine Million Dollar ausgesetzt hat. Gelöst ist bisher nur eine davon, die Poincaré-Vermutung.

Mixture-of-Experts

Bauweise, bei der ein Modell aus vielen Teil-Netzen besteht und pro Anfrage nur wenige davon rechnen. So bleibt ein sehr großes Modell bezahlbar.

Modellkarte

Das Datenblatt eines KI-Modells: wer es gebaut hat, wann es erschien, was es kann, welche Tests es bestanden hat und wo es versagt.

Monorepo

Ein einziges großes Quellcode-Archiv, in dem viele Projekte und Teams gemeinsam liegen, statt eines eigenen Archivs pro Programm. Vorteil: alles passt zusammen. Nachteil: das Archiv wird mit der Zeit riesig.

Multimodal

Ein Modell, das mehr als eine Eingabeart versteht, etwa Text, Bilder und Ton.

Müllverbrennung

Verbrennen von Abfall zur Entsorgung und zur Gewinnung von Strom und Wärme. Aus der übrigen Schlacke werden Metalle zurückgeholt.

Neutrino

Ein fast masseloses Teilchen, das Detektoren ungesehen durchquert. Seine Energie fehlt in der Messung und muss aus dem Rest des Ereignisses zurückgerechnet werden.

NIR-Sensor

Nahinfrarot-Sensor: Er erkennt Kunststoffsorten am zurückgeworfenen Licht, auch wenn sie mit bloßem Auge gleich aussehen.

Nutzlast

Wie viel Gewicht ein Roboter mit den Armen heben kann. Die Herstellerangabe gilt für kontrollierte Bewegungen, nicht für ein kurzes Reißen.

Offene Gewichte

Ein Modell, dessen trainierte Zahlenwerte zum Herunterladen veröffentlicht werden. Man kann es dann selbst betreiben und verändern - im Unterschied zu Modellen, die nur über eine fremde Schnittstelle nutzbar sind.

Offene Müllkippe

Unkontrollierte Ablagerung ohne Abdichtung: Sickerwasser und Methan entweichen, Brände sind häufig.

On-Device

Wenn ein Modell direkt auf dem Gerät rechnet – auf dem Handy oder Laptop – statt auf einem Server im Netz. Die verarbeiteten Daten verlassen das Gerät dabei nicht.

Open Source

Software, deren Quellcode offenliegt. Jeder darf sie lesen, verändern und weitergeben. Offenheit hilft beim Finden von Fehlern, ersetzt aber keine Pflege.

Parameter

Die gelernten Einstellwerte eines KI-Modells. Mehr Parameter bedeuten mehr Fähigkeit, aber auch mehr Speicher und Rechenzeit.

Patch

Ein kleines Software-Update, das einen konkreten Fehler behebt. Ein Sicherheits-Patch schließt eine bekannte Lücke.

Peer Review

Die übliche Qualitätskontrolle in der Wissenschaft: Andere Fachleute lesen eine Arbeit vor der Veröffentlichung und suchen Fehler. In der Mathematik gilt sie als das eigentliche Prüfsiegel.

Preprint

Eine wissenschaftliche Arbeit, die öffentlich abrufbar ist, aber noch keine Begutachtung durch unabhängige Fachleute durchlaufen hat. Die Ergebnisse darin sind vorläufig.

Prompt

Die Eingabe an ein Sprachmodell: Anweisung, Frage und mitgeschickter Kontext. Alles, was im Text steht, kann das Verhalten des Modells beeinflussen.

Prompt-Cache

Zwischenspeicher für Text, den das Modell schon einmal verarbeitet hat. Beginnt eine neue Anfrage mit demselben Text, liest das System ihn aus dem Speicher statt ihn neu zu durchrechnen - das ist schneller und viel billiger als frische Eingabe.

Prompt-Injection

Ein Angriff über versteckte Anweisungen in Inhalten, die ein Agent liest – etwa in einer Webseite, einer Mail oder einem Dokument. Der Agent hält den eingeschmuggelten Text für einen Auftrag und führt ihn aus.

Pruning

Beschneiden eines Modells: Unwichtige Verbindungen werden entfernt, damit es weniger Speicher und Rechenzeit braucht.

Pull Request

Ein Vorschlag, Änderungen in ein Projekt zu übernehmen. Er zeigt zeilenweise, was sich ändern soll, und wird von den Verantwortlichen geprüft, kommentiert und dann übernommen (englisch: merged) oder abgelehnt.

Quantenverschränkung

Zwei Teilchen verhalten sich wie ein gemeinsames System, auch wenn sie getrennt sind: Misst man das eine, steht das Ergebnis des anderen fest. Bei Top-Quarks lässt sich das am LHC nachweisen.

Quantil

Eine Stufe in einer Wahrscheinlichkeitsverteilung. Das 0,9-Quantil ist der Wert, den neun von zehn Fällen unterschreiten. Mehrere Quantile zusammen beschreiben nicht nur einen erwarteten Wert, sondern auch die Unsicherheitsspanne.

Quantisierung

Ein Modell wird mit weniger Bits pro Wert gespeichert, etwa vier statt sechzehn. Das spart Speicher, kostet aber etwas Genauigkeit.

Quellcode

Der für Menschen lesbare Text, aus dem ein Programm besteht. Ohne ihn ist Software eine Blackbox: Man kann nur von außen testen, nicht nachlesen.

RAG

Retrieval Augmented Generation: Das Modell bekommt zuerst passende Textstellen aus einer Datenbank geliefert und antwortet darauf gestützt.

Reasoning

Sichtbares Zwischendenken vor der Antwort. Reasoning-Modelle rechnen vor dem Ergebnis eine Kette von Schritten durch – das kostet mehr Rechenzeit, bringt aber bei Mathe und Logik mehr Treffer.

Rebound-Effekt

Wenn etwas effizienter und dadurch billiger wird, wird es häufiger genutzt – der Gesamtverbrauch kann trotz Sparsamkeit steigen. Auch Jevons-Paradox genannt.

Rechenzeit

Der Aufwand, den ein Rechenvorgang braucht: die Zeit auf einem Chip, gemessen in Sekunden, oder die Arbeit, gemessen in Operationen.

Rechenzentrum

Halle voller Server, in der KI-Modelle trainiert und betrieben werden – sie braucht sehr viel Strom und Kühlung.

Recyclingquote

Anteil des Abfalls, der stofflich verwertet wird. Die Zahl hängt stark davon ab, was mitgezählt wird — Sortierreste und Verbrennung werden je nach Statistik unterschiedlich behandelt.

Red-Teaming

Das absichtliche Angreifen eines eigenen Systems, um Schwachstellen zu finden, bevor andere es tun. In der KI-Forschung versuchen Menschen oder Programme, einem Modell verbotene Antworten zu entlocken.

Refusal

Die Weigerung eines Modells, eine Anfrage zu beantworten. Forscher messen sie als Prozentwert über viele Versuche – die Refusal-Rate.

Reinforcement Learning

Lernverfahren durch Ausprobieren: Das System erhält Belohnung für gute Ergebnisse und verbessert sein Verhalten dadurch selbst.

Remote Code Execution

Ein Angriff, bei dem jemand eigenen Code auf einem fremden Rechner ausführt, oft über das Netz und ohne Anmeldung. Kurz RCE.

Restmüll

Abfall für die graue Tonne, also alles, was nicht getrennt gesammelt wird.

Reward Hacking

Wenn ein Modell nicht die Aufgabe löst, sondern einen Weg findet, die Belohnung dafür trotzdem zu kassieren – etwa die Lösung abschreibt oder einen Test austrickst. Von außen sieht das nach Erfolg aus, ist aber keiner.

Rezyklat

Kunststoff, der aus gesammeltem Altmaterial neu hergestellt wurde, im Gegensatz zu Neuplastik aus Erdöl.

RLHF

Reinforcement Learning from Human Feedback: Menschen bewerten die Antworten eines Modells, und nach diesen Bewertungen wird es nachtrainiert.

Sandbox

Eine abgeschottete Spielumgebung: Programme laufen darin ohne Zugriff auf echte Dateien oder das Netz. Behauptet ein Text, die Antwort lande nur in so einer Testumgebung, kann das das Verhalten eines Modells ändern.

Scaffolding

Die Hülle um ein Modell: Werkzeuge, Regeln und Zwischenschritte, mit denen es eine Aufgabe mehrstufig löst, statt sofort zu antworten.

Sicherheitsupdate

Eine Aktualisierung, die bekannte Sicherheitslücken schließt. Bleibt sie aus, wächst das Risiko mit jedem neu entdeckten Fehler.

Signifikanz

Die statistische Stärke eines Messsignals, angegeben in Sigma. Drei Sigma gelten als Hinweis, fünf Sigma in der Teilchenphysik als Entdeckung.

Sim-to-Real

Eine Bewegung wird zuerst in der Computersimulation geübt und dann auf den echten Roboter übertragen. Kleine Unterschiede zwischen Simulation und Wirklichkeit lassen das oft scheitern.

Skalierungsgesetz

Faustregel aus Messreihen: Die Leistung eines Modells wächst vorhersagbar mit Rechenleistung, Datenmenge und Modellgröße – lange galt: größer ist besser.

Skill

Eine Sammlung von Anweisungen und Dateien zu einem Thema, die ein Modell bei Bedarf nachlädt - etwa die Hausregeln für ein Projekt. So muss nicht alles dauerhaft im Prompt stehen.

Spezifikation

Die Beschreibung, was ein Programm tun soll, aufgeschrieben so genau, dass man es prüfen kann. Ein Beweis zeigt nur, dass der Code diese Beschreibung erfüllt - nicht, dass die Beschreibung das Richtige verlangt.

Standardmodell

Das Standardmodell der Teilchenphysik beschreibt alle bekannten Elementarteilchen und drei der vier Grundkräfte. Es ist extrem genau geprüft – aber es erklärt zum Beispiel Dunkle Materie nicht.

State-Space-Modell

Eine alternative Bauweise zu den üblichen Aufmerksamkeits-Modellen: Der Text wird Schritt für Schritt durchgerechnet, der Rechenaufwand wächst dabei nur linear mit der Textlänge. Das spart Rechenzeit bei langen Texten.

Störerhaftung

Haftung für eine Rechtsverletzung, die man selbst verursacht oder bewusst unterstützt hat - auch ohne eigenes Verschulden. Im Internet trifft sie Plattformen und Suchmaschinen, sobald sie von einem rechtswidrigen Inhalt wissen.

Störstoff

Material, das im falschen Behälter landet oder die Anlage blockiert — von der Plastiktüte im Biomüll bis zum Metallstück im Papier.

Subagent

Ein zweiter Modellaufruf mit eigenem Kontextfenster, den ein Agent für eine Teilaufgabe startet. Der Unteragent sieht nur seine Aufgabe statt des ganzen Gesprächs und liefert ein zusammengefasstes Ergebnis zurück.

Taktzeit

Die Zeit für einen Arbeitsgang. Beim Sortieren heißt das: wie viele Griffe pro Minute möglich sind.

Teleoperation

Ein Mensch steuert den Roboter aus der Ferne. Was nach Autonomie aussieht, ist dann Handarbeit.

Temperatur

Eine Einstellung, die steuert, wie gleichförmig oder überraschend ein Modell formuliert. Niedrig wirkt sachlich, hoch wirkt kreativ.

Testzeit-Compute

Rechenaufwand, den ein Modell erst beim Beantworten einer Frage einsetzt – etwa mehrere Lösungswege parallel durchrechnen und den besten auswählen.

Token

Das Wortstück, in das ein Sprachmodell Text zerlegt. „Roboter“ kann in „Robot“ und „er“ zerfallen. Rechenaufwand und Kontextlänge werden in Token gemessen.

Transformer

Die neuronale Netzarchitektur hinter fast allen heutigen Sprachmodellen. Kernstück ist die Aufmerksamkeit (Attention): Das Modell gewichtet, welche Teile der Eingabe füreinander wichtig sind.

Verbundmaterial

Mehrere Materialschichten, die fest verklebt sind, etwa Getränkekarton oder Chipstüte. Sie lassen sich kaum in reine Sorten trennen.

Verifier

Eine Prüfinstanz, die Antworten automatisch bewertet – etwa ein Testprogramm, das generierten Code ausführt, oder ein zweites Modell als Prüfer.

Versionsverwaltung

Das Programm, das alle Änderungen an Software speichert und verwaltet, meist Git. Es merkt sich, wer wann was geändert hat, und erlaubt, zu früheren Ständen zurückzuspringen.

Wasserzeichen

Eine unsichtbare Markierung in einem Werk, etwa in einem Text, Bild oder Ton. Sie soll maschinell erkennbar machen, dass ein KI-System den Inhalt erzeugt hat - ähnlich dem Wasserzeichen im Papier, das man erst gegen das Licht sieht.

Weltmodell

Ein KI-Modell, das eine Umgebung nicht beschreibt, sondern selbst Bild für Bild erzeugt – eine Welt, in der man sich bewegen und die man im Lauf verändern kann. Bekannt für Trainingsumgebungen von Robotern und für Spielprototypen.

Wirbelstromabscheider

Ein Gerät, das Metalle wie Aluminium mit einem Magnetfeld aus dem Abfallstrom herauswirft.

Zeitreihe

Messwerte, die in festem Takt anfallen: der Stromverbrauch eines Werks jede Viertelstunde, der Pegel eines Flusses pro Minute, der Umsatz eines Ladens pro Tag.

Zero-Shot

Ein Modell löst eine Aufgabe, für die es nicht eigens trainiert wurde. Bei Vorhersagemodellen heißt das: Es rechnet auf einer Datenreihe, die es nie zuvor gesehen hat.

Ökodesign

EU-Vorgaben, die Umweltanforderungen an Produkte stellen - etwa Reparierbarkeit, Ersatzteile und die Dauer der Update-Versorgung.
