Hallo und willkommen bei Hermies Blog, der Hörfassung unserer Artikel über KI, Modelle und Agenten. Heute geht es um llama punkt cpp, die Bibliothek, mit der lokale Sprachmodelle auf gewöhnlichen Rechnern laufen, und um die Frage, was die neue Versionsnummer eins Punkt null wirklich bedeutet.

Zuerst die Kurzfassung. Die Organisation ggml org hat am dreizehnten November zweitausendsechsundzwanzig um zehn Uhr zwanzig UTC die Version eins Punkt null von llama punkt cpp veröffentlicht. Die Tensor Bibliothek ggml, auf der die Berechnung läuft, geht zur selben Stunde auf eins Punkt null. Die eins Punkt null ist vor allem ein Versprechen an alle, die den Code einbinden. Ab jetzt zeigt eine neue Hauptversion eine inkompatible Schnittstelle an. Dafür fallen fünfunddreißig veraltete Funktionen aus der öffentlichen Header Datei. Technisch bringt das Release neue Speicherformate für den Zwischenspeicher, einen Cache für die Experten von Mixture of Experts Modellen und einen gegen Angriffe gehärteten Server. Dreieinhalb Jahre nach dem ersten Commit stehen einhundertvierunddreißigtausendachthundertzweiundsechzig Sterne, fünfundzwanzigtausendfünfhundertdreiundfünfzig Forks, vierhundertsiebenundvierzig Beitragende und zweitausendsechshundertvier offene Issues. Und ein Fork mit dem Namen Strata, der auf demselben Code aufsetzt, schreibt in einem Vergleich aus der Gemeinschaft zweieinhalbmal schneller.

Was ist passiert. Der Anlass ist kein neues Modell, sondern die Verantwortung gegenüber denen, die den Code einbauen. Im Blogbeitrag heißt es, jede neue Integration bedeute mehr Entwickler, die von den Schnittstellen abhängen, und deshalb sei eine flexible, aber stabile Schnittstelle entscheidend. Konkret gilt jetzt eine einfache Regel. Ein Wechsel der Hauptversion zeigt eine inkompatible Schnittstelle an, ein Wechsel der Nebenversion eine rückwärtskompatible Erweiterung, eine Fehlerbehebung ohne Schnittstellenänderung bleibt bei der letzten Ziffer.

Der Preis für diese Klarheit steht in den Release Notizen. Fünfunddreißig als veraltet markierte Funktionen sind verschwunden, dazu eine Funktion zum Vorwärmen des Modells und ein Parameter für die Speicheraufräumung. Wer eigene Anwendungen gegen die Bibliothek baut, muss diese Stellen suchen, bevor er aktualisiert.

Inhaltlich ist das Release kein reines Aufräumen. Der Zwischenspeicher für bereits berechnete Textteile kann jetzt in einem kompakten Format mit acht Bit arbeiten. Für Modelle mit vielen kleinen Experten gibt es einen Cache im Hauptspeicher, dessen Anteil am Prozessor sich einstellen lässt. Dazu kommen das Nachladen externer Gewichtsdateien, vier neue Modellarchitekturen, ein Endpunkt für Sprachausgabe nach dem Muster von OpenAI und ein neu gebauter Web Client für den Server. Sicherheitsrelevant sind vier Reparaturen. Sie betreffen Anfragen, die der Server an fremde Adressen schickt, die Freigabe von Schnittstellen für fremde Webseiten, das Umleiten von Namen im Netz und den Abbruch von Werkzeugaufrufen.

Warum zählt das. Die Zahl eins Punkt null ist in der Softwarewelt eine Zusage und keine Leistung. Sie sagt, dass ein Projekt seine Schnittstelle für ernst genug hält, um sie zu versionieren. Für llama punkt cpp wiegt das mehr als bei den meisten Projekten. Vierhundertsiebenundvierzig Menschen haben Code beigetragen, das Repository hat einhundertvierunddreißigtausendachthundertzweiundsechzig Sterne, und die Bibliothek ist die Grundlage für eine ganze Klasse von Anwendungen, die lokale Modelle auf Laptops, Servern und kleinen Rechnern laufen lassen.

Der zweite Grund ist unangenehmer. Das Projekt trägt seit Monaten eine Debatte über sein Tempo mit sich, und die eins Punkt null hat sie nicht beendet. In der Diskussion auf Reddit, mit siebenhundertvierundvierzig Punkten und neunzig Kommentaren derzeit der sichtbarste Ort zum Thema, ist der bestbewertete Kommentar keine Gratulation, sondern eine Bitte. Bitte fügt dem Projekt mehr Betreuer hinzu, es gibt buchstäblich eine Tonne offener Fehlerberichte und Änderungsvorschläge. Ein Antwortkommentar mit fünfundsechzig Punkten nennt den Grund. llama punkt cpp sei gegenüber Projekten wie Strata deutlich zurückgefallen, beim Nachladen von Gewichten von der Festplatte sei der Fork inzwischen weit vorn, und die Geschwindigkeitsgewinne kämen nicht mehr im Wochentakt.

Ein Beleg für die Wartezeit lässt sich nachprüfen. Der Änderungsvorschlag, der das Modell Dory unterstützt, liegt seit dem zehnten Oktober offen, ohne Zusammenführung, mit zwanzig Kommentaren. Ein Modell, das in dieser Branche im Oktober interessant war, ist im November alt.

Der Gegenpunkt kommt in derselben Diskussion und ist ebenfalls richtig. llama punkt cpp läuft auf Grafikkarten und Prozessoren, für die andere Programme keinen Code bauen. Strata unterstützt keine alte Hardware wie llama, schreibt ein Kommentar, und ein anderer nennt die fertigen Container Pakete für die drei großen Beschleuniger Familien als Grund, warum er bleibt. Herunterladen, Modell daneben legen, starten. Die Spitze ist woanders, die Fläche ist hier.

Was heißt das praktisch. Wer die Bibliothek in eine eigene Anwendung einbindet, sollte jetzt gegen die Version eins Punkt null bauen und die Liste der entfernten Funktionen abarbeiten. Danach zeigt jede Aktualisierung, ob sie bricht. Das ist der eigentliche Gewinn dieser Veröffentlichung.

Wer lokale Modelle mit vielen Experten fährt und dabei Speicher knapp wird, hat zwei neue Schrauben. Die Gemeinschaftsmessung zeigt aber auch die Grenze. Bei einer Karte, auf die das Modell vollständig passt, kostet der Cache rund zehn Prozent Durchsatz gegenüber dem normalen Laden, weil statt zwei Rechenschritten pro Token fünfzig anfallen. Der Cache ist ein Werkzeug für den Fall, dass das Modell nicht passt, und keine allgemeine Beschleunigung.

Wer das Maximum aus einer Karte herausholen will, muss messen statt annehmen. Die Zahlen aus dem Vergleich mit Strata sind deutlich. Einhundertein Token pro Sekunde gegen dreiundvierzig bei einem Modell, das vollständig in den Speicher passt, und drei Komma vier statt neun Komma acht Sekunden bis zum ersten Token bei einem langen Prompt. Sie stammen aus einem einzigen Diskussionsfaden, einer Grafikkarte und einem Modell, mit drei Läufen pro Messpunkt. Für eine Kaufentscheidung ist das zu wenig, für einen Test auf der eigenen Hardware ein guter Anlass.

Wer auf neue Modelle angewiesen ist, sollte die Geschwindigkeit der Zusammenführungen beobachten und nicht die Versionsnummer. Der Tag eins Punkt null ändert daran nichts. Was nicht zusammengeführt wird, fehlt in der Bibliothek, egal wie sauber die Schnittstelle versioniert ist.

Für die langfristige Planung ist die Verteilung der interessantere Teil des Releases. llama punkt cpp liegt als Paket für Homebrew, Debian, conda forge, MacPorts, Winget und als Rahmenwerk für Apple Plattformen bereit, dazu Container und fertige Archive für Linux, Mac, Windows, Android und iOS. Ein Projekt, das diesen Aufwand betreibt, ist nicht auf dem Rückzug. Es hat nur Konkurrenz bekommen, die schneller ist und dafür schmaler.
