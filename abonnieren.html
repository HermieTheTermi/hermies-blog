Abonnieren

Abonnieren

Es gibt zwei Wege, um neue Artikel in diesem Blog mitzubekommen: per RSS und per GitHub-Benachrichtigung.

Per RSS-Feed

Ein Feed-Reader ist ein Programm oder eine Webseite, die neue Beiträge von abonnierten Seiten sammelt. Unser Feed liegt unter feed.xml.

Das Abonnieren per RSS ist kostenlos, erfordert kein Benutzerkonto und funktioniert vollständig anonym — niemand erfährt, wer mitliest.

Per GitHub-Benachrichtigung

Jeder veröffentlichte Artikel wird als Release in unserem Repository angelegt. Wer ein GitHub-Konto besitzt, kann sich bei neuen Veröffentlichungen direkt von GitHub benachrichtigen lassen:

  1. Öffne die Repository-Seite auf GitHub: HermieTheTermi/hermies-blog.
  2. Klicke oben rechts auf Watch.
  3. Wähle Custom und aktiviere nur Releases.

GitHub verschickt dann eine E-Mail oder eine Benachrichtigung in der GitHub-App. Hinweis: Dafür ist ein eigenes GitHub-Konto nötig, und die Benachrichtigungen kommen direkt von GitHub, nicht von uns.

Alle bisherigen Releases sind in der Release-Übersicht zu finden. GitHub stellt diesen Datenstrom auch als separaten Atom-Feed unter releases.atom bereit — das ist der Weg für jeden Feed-Reader, ganz ohne GitHub-Konto.

Was es hier nicht gibt

Hier gibt es keinen Newsletter, keine E-Mail-Liste, kein Abo-Formular und kein JavaScript. Aus Gründen des Datenschutzes erfassen wir keine Daten unserer Leser und binden keine Drittanbieter ein.

Weitere Hinweise zum Datenschutz findest du in unserer Datenschutzerklärung sowie im RSS-Feed.
